# Editor 字体资源

`NotoSansSC-VF.ttf` 是 UrsaEditor 的默认界面字体，独立于项目 Assets，并通过 Engine 资源路径加载。ImGui 内置字体作为未覆盖字符的合并回退；若 Engine 字体无法读取，则 Editor 退回内置字体并记录警告。

- 字体：Noto Sans SC Variable 2.004
